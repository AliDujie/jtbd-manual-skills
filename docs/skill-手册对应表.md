## 说明

- **编号即篇目**：仓里目录名带篇号前缀（如 `05-jtbd-sampling-design`），方便按文章查找；安装时去前缀，使目录名与 frontmatter `name` 一致。
- **每件自足**：任何一件 skill 都不依赖其他 skill 目录，单独复制即可使用；字段契约、校验脚本、理论字典随包分发。
- **放开节奏**："待放出"的 skill 已在本仓外打磨，随对应篇目发布时入库；本篇目表随每次放开更新。
