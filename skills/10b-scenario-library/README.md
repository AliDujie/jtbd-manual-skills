# scenario-library

从 35 列 JTBD 场景库（Excel）生成深度分析 HTML 报告：场景合并分层、四力分析与净推动力、田字格优先级矩阵、竞争格局、创新信号分级、精选处方与行动路线图，精华版加完整版双 Tab 单文件输出。

## 本包内容

- `SKILL.md` — 执行流程、硬规则、报告规范与内嵌的 Python 校验脚本
- `jtbd_essentials.md` — 四力、竞争三分类、创新信号、Job Map 等理论字典
- `swd_essentials.md` — 图表选择、注意力引导、叙事结构等展现方法论

两个理论字典是运行时查找数据，必须随本包一同分发；缺失时按表内字段定义降级工作。

## 使用

把整个目录复制到 Agent 的 skills 目录，目录名去掉 `10b-` 前缀、与 `SKILL.md` 中 `name` 字段一致（即 `scenario-library`），随后按所用工具的说明重载。准备一份 35 列场景库 Excel；字段名尽量与 `SKILL.md` 的映射表一致。手上是 Markdown 表时，先另存为 xlsx，表头保持 35 列顺序，不要先改列名。

报告默认输出单文件 HTML，含精华版与完整版两个 Tab。

## 边界

报告里的净推动力、田字格、S/A/B/C 分级都是分析辅助，不是立项决定；样本量小、字段缺失多或单人主题多时，结论要相应降级。ODI 机会分数需要重要度、满意度问卷量测，本包不计算，也不要求上游补这两列。
