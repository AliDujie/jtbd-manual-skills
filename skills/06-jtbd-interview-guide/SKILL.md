# 访谈提纲生成

## 触发场景

- 采样计划完成，进入访谈准备
- 需要根据不同假设生成对应类型的提纲
- 团队成员写的提纲太浅，需要挖深
- 迭代访谈过程中调整提纲

## 核心能力

### 能力一：三型访谈选择器

根据研究目标推荐最合适的访谈类型：

| 研究目标关键词 | 推荐类型 |
|---|---|
| 用户为什么切换 / 新方案接受度 / 从 A 到 B 的转换 | **Switch 访谈**（切换访谈） |
| 用户对每一步的重要性满意度 / 机会分数 / 量化优先级 | **ODI 访谈**（成果驱动） |
| 用户为什么流失 / 使用后不再用 / 放弃使用 | **Churn 访谈**（流失回溯） |

也可以混合——如"Switch 主线 + ODI 补量化"。

### 能力二：五段结构骨架

标准提纲骨架：

1. **预热段（5 分钟）**：建立信任、放松状态、简单背景
2. **主线段（20-30 分钟）**：按研究假设铺开的主问题串
3. **深挖段（15-20 分钟）**：针对主线段的关键节点做 5-Why 追问
4. **竖井段（10-15 分钟）**：针对最重要的一个假设做深度挖掘
5. **尾问段（5 分钟）**：兜底追问 + 未来意向 + 谢访

每段配对应时长控制、主问句、备用问句。

### 能力三：十必问模块组合

十个 JTBD 必问模块，根据研究假设灵活组合：

1. 挣扎时刻（用户何时开始想改变）
2. 竞争格局（用户还看过什么）
3. 推力（对旧方案不满什么）
4. 拉力（新方案吸引什么）
5. 焦虑（担心什么）
6. 惯性（为什么一直没换）
7. 进步验证（换了之后有什么变化）
8. 功能验证（具体在哪个场景/怎么用）
9. 补偿行为（现在怎么凑合）
10. 切换触发点（什么事件让你决定要换）

每个模块给出 2-3 个主问句 + 5-Why 追问模板。

### 能力四：AI 辅助反推能力

根据某一具体假设，AI 帮反推出 3-5 个可以验证该假设的开放式问题。人可对生成结果做增删。

### 能力五：追问艺术模块（本 skill 内嵌指南）

包含 5-Why 使用边界、沉默的价值、如何避免引导性提问、如何在被访者跑题时软性拉回等实操技巧。

## 输出形态

一份完整访谈提纲（Word / Markdown），包含：
- 提纲基本信息（研究目的、访谈类型、时长）
- 五段结构 + 每段主问句 + 追问模板
- 引导语（开场白 + 结束语）
- 访谈者内部备注（哪些题必问、哪些可跳）

## 常见踩坑（本 skill 内置校验）

- 提纲太长塞满 90 分钟（本 skill 强制时长控制在 60 分钟以内）
- 每个模块只有主问句、没有追问储备（强制生成 5-Why 模板）
- 引导性提问（"你是不是觉得 X"）→ 本 skill 自动扫描并提示修改
